RRelease tracker

Release tracker cannot open its accounts

Nobody can sign in until the accounts file is restored or reset. Everything else keeps running.
Accounts file
/config/accounts.db
Error
The file cannot be read.
Backups
/config/backups/

  1. Restore the accounts from one of the backups, with its file name in place of <archive>:

    docker exec release-tracker release-tracker accounts restore <archive>
  2. A reset deletes every account with its passkeys, sessions and API keys, the sign-in settings and the security log. The library and the settings stay.

    Or start the accounts again, which opens the first-run setup with a new setup token:

    docker exec release-tracker release-tracker accounts reset

Reload this page once the command has finished.
