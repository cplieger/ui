Prose

Every construct, headings from h2

One answer holding each piece once: emphasis, strong, struck words, a long path in inline code that breaks anywhere, a line break, nested and numbered lists, task boxes, a quote, a table, an equation, a rule, an image in its link form and a code block. Its # renders as h2, under the card's own title.

The same, headings from h4

With headingLevel: 4 the same text fits under a page's h3; its ### reaches h6, which keeps a size and weight of its own.

Code blocks

Go

The bar names the language and holds Copy, which writes the block's text and turns into a check. Keywords, strings, numbers and comments each take a syntax colour, at least 4.5:1 on the block in both themes.

TypeScript

The fence's tag is ts; the label says TypeScript.

A change

An added line has a green fill and its +, a removed one a red fill and its -, so the sign says it without the colour. The fills span the block's widest line.

No tag, detected

The fence has no tag. Detection reads the first lines, finds Python and labels and colours it so; when it is unsure, the block stays plain with no label.

A tag the highlighter does not know

The label is the tag as written, and the text stays plain.

A long line

A command never wraps, since a wrapped one reads as two. The block scrolls instead, and takes a tab stop only while it overflows, so a keyboard can scroll it too.

An app's button beside Copy

The app adds Run to the block's actions from its code hook, once the fence has closed. Press it for a notice.

Tables

A wide table in its region

A table wider than its box scrolls inside its own outlined region, never the page. While it overflows the region is a tab stop named Table; once it fits, it is neither. Each column keeps the alignment the text gave it.

Live

Paste agent text

What you type or paste renders below on the next frame, with the same options an app uses by default: links checked, images as links, at most 1 MiB.

Safety

A refused link

A javascript: destination gets no href, so its words read as body text and do nothing.

A withheld link

An address that could carry data out, here a long encoded query, renders without href and shows where it leads, so a person can read it and copy it on purpose.

An image in its link form

An image is a link to its source, named by its alt text, so nothing is fetched until a person asks for it.

Raw HTML as text

Tags in the text are shown as the characters they are; nothing in the text becomes markup.
