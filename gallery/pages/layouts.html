Layouts and screens

Frames without content: the regions an app fills, how each moves between a phone, a tablet and a desktop, and the few arrangements used inside a region. A component never knows which region holds it; it sizes to its container, so it moves between regions unchanged.

App frame

templates/app.html, on .cp-app: the header across the top (the mark, the destinations, then the toolbar: the header status, the theme, the global actions, the account last), the rail of filters beside main, the status line at the foot with the freshness fact first. Main holds, in order, the banner, the heading row with the page's actions, the screen's notices and the content, at most 90rem wide and centred. Under 60rem the rail leaves and the Filters button opens it in a sheet; under 40rem the destinations move to a bar at the window's foot. A tool has no page footer: the status line is its foot. Each region and slot is named by a comment in the file. Open the template.

List and detail

templates/list-detail.html: the app page whose main holds .cp-list-detail, a list of row links and the detail they open. The detail docks beside the list once main is 52rem wide and opens as a full-height sheet at the inline end below that, with Back closing it; enhanceListDetail and the app's route open it, so the template shows the list with its detail closed. It keys on main's width, not the window's. Open the template.

Gate page

.cp-gate: a page outside the app frame for one short task, its mark and name over one panel and at most one line under it. templates/gate.html leaves the panel empty for the app's own screen to fill: its <h1>, a notice slot and its form; templates/gate-steps.html, shown here, is its steps form for a first-run setup: the step track, or "Step 2 of 3" on a phone, each done step a link back, the step's heading, its form and Back before the one primary. Each step is its own address, so the page needs no script. Open the gate, open the steps form.

A gate page with no script

templates/gate-message.html: the page a server sends when it cannot serve the app, such as a store that will not open. It runs no script and paints under default-src 'none'; style-src 'self'; img-src 'self' data:; font-src 'self': what happened as its heading, a danger notice naming the kind of error, the facts, the remedies as numbered steps, each command a code block that one click selects whole, a warning leading the one that needs it, and the build version as the line under the panel. It holds no control, since the page accepts nothing. Open the template.

Accounts unavailable

templates/accounts-unavailable.html: the page with no script, filled for an app whose accounts file cannot open. The server sends it for every page, so nobody can sign in while everything else keeps running. This is one filling: the server writes the file's path or setting name, the error's sentence and the command lines. It says what happened, the file and its error, where the backups are, then the two commands to run in the container, each a code block that one click selects whole, the warning naming what a reset deletes leading the reset. Open the page.

Not found

templates/not-found.html: the app page for an address that matches no screen, its content slot holding .cp-empty[data-variant="page"]: the glyph, the heading, one sentence and the one link home. It keeps the header status and main's urgent part, with no destination current, since the person is still inside the app; a server that cannot serve the app at all sends the gate page with no script instead. Open the template.

.cp-mark holding an <img> or an inline <svg> in place of its letter: the image fills the mark's box at its own aspect ratio and the letter's fill goes. An svg drawn in currentcolor takes the header's ink, and on a gate page the ink of the name beside it, in both themes. A fixed-colour logo whose colours hold on both themes is one image, shown in both (the third header). One that needs a version per theme comes as two images, data-cp-scheme="light" and "dark", and the stylesheet shows the one that matches the page's theme, chosen or the system's, with no script. Beside the written name the image takes alt=""; a mark alone takes the name as its alt. Switch the gallery's theme to see the second header's image change.
